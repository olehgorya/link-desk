# Link Desk

[Открыть приложение](https://link-desk-oleg.neatsky2048.chatgpt.site)

Реестр партнёрских ссылок без установки. Бета 0.3 поддерживает гостевую локальную базу и личную облачную базу после входа Google.

## Быстрый старт

1. Откройте сайт. Без входа карточки сохраняются только в этом браузере.
2. Для личной облачной базы нажмите «Войти через Google». На этапе тестирования Google допускает настроенные тестовые аккаунты.
3. Добавьте карточку с партнёром, оффером, GEO и готовой ссылкой.
4. Если у вас есть локальные записи, после входа нажмите «Перенести локальные записи». Перенос требует подтверждения, пропускает демо и совпадающие ID и сохраняет локальную базу.
5. На другом устройстве войдите тем же Google-аккаунтом. Для получения последних изменений используйте «Обновить базу».
6. Регулярно сохраняйте «Экспорт JSON».

## Работа с данными

Облачные изменения подтверждаются сервером. При сбое карточка остаётся открытой; перед повтором проверьте базу обновлением. Если запись изменена на другом устройстве, сохранение устаревшей версии отклоняется. Скопируйте несохранённые поля, закройте карточку и обновите базу. Фоновой синхронизации и офлайн-редактирования облака нет.

Гостевой импорт заменяет базу после подтверждения. Облачный импорт добавляет карточки, пропуская совпадающие ID; он не заменяет и не удаляет существующие записи. Экспорт содержит партнёрские данные и историю URL. Храните его конфиденциально.

Выход возвращает гостевую базу. Облачные карточки не удаляются. Общих командных пространств нет. Вход по почте пока не включён: для публичной отправки писем требуется настроить SMTP в Supabase.

## Настройка Supabase для разработчика

Выполните `supabase/migrations/202610290001_personal_links.sql`. Таблица `linkdesk_links` использует составной ключ `(user_id, id)` и принудительный RLS. Браузер использует только publishable key. **Никогда не добавляйте service_role, Secret key или Google Client Secret в исходники.** Google Client Secret хранится только в настройках провайдера Supabase.

В Google OAuth-клиенте типа Web application настройте origin сайта и callback URL проекта Supabase `/auth/v1/callback`. Site URL и разрешённый Redirect URL Supabase должны соответствовать публичному адресу сайта. Публичные параметры подключения указаны в `dist/cloud.js`. OAuth использует PKCE; вход нужно завершить в том же браузере, где он был начат. Локальный preview не инициирует production-вход.

SDK `@supabase/supabase-js` 2.118.0 включён локально в `dist/vendor/supabase.js` (MIT). Версия фиксирована в исходниках; внешнего CDN при запуске нет.

## Локальный запуск

Скачайте ZIP, распакуйте и выполните из папки проекта:

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

Откройте http://localhost:8080. Гостевой режим работает без настройки Supabase. Публичный OAuth настроен для размещённого сайта.
