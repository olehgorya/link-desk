# Link Desk

Реестр партнёрских ссылок для affiliate managers: партнёры, офферы, GEO, готовые ссылки и история их замены — в одном месте.

## Начать пользоваться

**[Открыть Link Desk →](https://link-desk-oleg.neatsky2048.chatgpt.site)**

Приложение доступно публично и работает в браузере. Для обычного использования не нужно скачивать этот репозиторий, устанавливать Python или запускать команды.

1. Откройте сайт.
2. Изучите вымышленные примеры или нажмите **«Убрать демо»**, чтобы начать с пустого реестра.
3. Нажмите **«Добавить ссылку»**.
4. Укажите партнёра, оффер, GEO и готовую ссылку, полученную от интегратора. При необходимости добавьте статус, дату передачи, источник и комментарий.
5. Нажмите **«Сохранить»** — карточка появится в реестре.

Ссылки должны начинаться с `https://` или `http://`. Названия партнёров и GEO лучше записывать единообразно, например всегда `UA`.

## Как работать со ссылками

### Найти нужную карточку

Используйте поиск по партнёру, офферу, ссылке, GEO, источнику или комментарию. Поиск можно сочетать с фильтрами GEO и статуса. Звёздочка возле карточки добавляет её в **«Избранное»**.

### Передать ссылку партнёру

1. Скопируйте URL кнопкой рядом со ссылкой в таблице.
2. Либо откройте карточку нажатием на название оффера и выберите **«Подготовить сообщение»**.
3. Отредактируйте текст при необходимости, скопируйте его и отправьте партнёру в своём мессенджере.
4. После отправки самостоятельно измените статус на **«Передана»** и укажите дату.

Link Desk подготавливает текст, но не отправляет сообщения и не меняет статус автоматически.

### Заменить ссылку

Откройте карточку, вставьте новый URL и сохраните. Прежний URL останется в разделе **«Предыдущие версии ссылки»**. История хранит заменённые ссылки, а не все изменения полей карточки.

Статус **«Остановлена»** — отметка в реестре: он не отключает ссылку в трекере или у рекламодателя.

## Где хранятся данные

У каждого посетителя своя база в его браузере. Карточки сохраняются локально (localStorage) и не передаются в общую базу Link Desk. Другие посетители сайта не видят ваши записи.

- Используйте один и тот же браузер и профиль.
- Автоматической синхронизации между устройствами и совместного доступа команды пока нет.
- Очистка данных сайта может удалить базу. Режим инкогнито не подходит для постоянного хранения.
- Локальная копия приложения и публичный сайт имеют отдельные хранилища.

### Резервная копия и перенос

Нажмите **«Экспорт JSON»**, чтобы скачать базу с карточками и историей ссылок.

Для переноса откройте Link Desk в другом браузере или на другом устройстве, нажмите **«Импорт JSON»**, выберите экспортированный файл и подтвердите восстановление.

**Импорт полностью заменяет текущую базу, а не объединяет записи.** Перед импортом сохраните экспорт имеющихся данных. Поддерживается файл экспорта Link Desk размером до 10 МБ.

Экспорт содержит ваши партнёрские ссылки и комментарии. Передавайте его только тем, кому разрешён доступ к этим данным.

Если вы уже работали с локальной копией, сначала сделайте в ней экспорт, затем импортируйте его на публичном сайте.

## Возможности и ограничения

- Создание, редактирование и удаление карточек.
- Поиск, фильтры GEO и статуса, избранное.
- История замены URL.
- Копирование ссылки и подготовка сообщения партнёру.
- Экспорт и восстановление базы JSON.
- Демонстрационные записи с вымышленными названиями и URL.

Это первая версия продукта. Приложение не проверяет доступность офферов, редиректы или корректность интеграции. Подключений к CRM, трекерам и мессенджерам пока нет. Удаление карточки удаляет и её историю; восстановить её можно из ранее сохранённой резервной копии.

## Локальный запуск — дополнительно

Этот раздел нужен только тем, кто хочет запускать приложение на своём компьютере или дорабатывать исходники. Для работы через публичный сайт он не требуется.

Скачайте репозиторий через **Code → Download ZIP** и полностью распакуйте архив. Файлы внутри `dist` должны оставаться вместе.

Для быстрого просмотра откройте `dist/index.html` в современном браузере. При открытии файла напрямую работа буфера обмена и локального хранилища может зависеть от ограничений браузера.

Для запуска через локальный сервер выполните из корневой папки проекта:

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

На Windows можно использовать:

```bat
py -m http.server 8080 --bind 127.0.0.1 --directory dist
```

Откройте http://localhost:8080 и оставьте окно сервера открытым на время работы. Для остановки нажмите Ctrl + C. Для этого варианта нужен установленный Python; сборка, дополнительные зависимости и API-ключи не требуются.

## Структура проекта

- `dist/app.js` — логика и локальное хранение.
