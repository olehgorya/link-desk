# Link Desk

Локальный реестр партнёрских ссылок. MVP для affiliate managers: готовая ссылка, партнёр, оффер, GEO, статус и контекст выдачи.

## Запуск

Откройте `dist/index.html` или запустите статический сервер из `dist`:

```sh
python -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Сборка, зависимости и API-ключи не требуются.

## Возможности

- Создание, редактирование и удаление карточек.
- Поиск, фильтры GEO и статуса, избранное.
- Сохранение прежних URL при замене ссылки.
- Копирование URL и подготовка сообщения партнёру.
- Экспорт и восстановление базы JSON.
- Вымышленные демо-записи с возможностью удаления.

Данные находятся в localStorage текущего браузера и домена. Синхронизации между устройствами нет. Очистка данных сайта удалит базу: регулярно делайте экспорт. Смена домена создаёт отдельное хранилище. Приложение не проверяет работоспособность офферов и не интегрировано с CRM или мессенджерами.

## Структура

- `dist/index.html` — интерфейс
- `dist/style.css` — адаптивное оформление
- `dist/app.js` — логика и хранение
